# Gambar Digital Connectivity

Taruh gambar tiap fitur di folder produknya dengan nama file persis seperti di bawah
(ekstensi boleh png / jpg / webp / svg). Bila file belum ada, halaman memakai gambar bawaan.

Folder: `ferroir/` dan `fermego/`

| Nama file (tanpa ekstensi) | Item yang diklik        |
| -------------------------- | ----------------------- |
| `controlled-fermentation`  | Controlled Fermentation |
| `remote-monitoring`        | Remote Monitoring       |
| `batch-logging`            | Batch Logging           |
| `recipe-management`        | Recipe Management       |
| `product-passport`         | Product Passport        |

Rasio ideal sekitar 1 : 1,1 (kartu kanan di desain). Gambar diisi penuh (cover).
